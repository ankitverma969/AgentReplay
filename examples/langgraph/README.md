# LangGraph Examples

These examples show how the optional LangGraph adapter is intended to be used.
Install LangGraph before running them:

```bash
pip install "agentreplay[langgraph]"
```

Files:

- `basic_graph.py`
- `async_graph.py`
- `streaming_graph.py`
- `parallel_graph.py`
- `checkpoint_graph.py`
