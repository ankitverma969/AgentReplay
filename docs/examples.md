# Examples

The repository includes runnable examples:

- `examples/manual_recording.py`
- `examples/sqlite_storage.py`
- `examples/replay_recording.py`
- `examples/diff_recordings.py`
- `examples/openai_agents/`
- `examples/langgraph/`
- `examples/extensions/`

Examples are designed to avoid real secrets. Adapter examples use framework
imports only inside example entrypoints so the base package remains lightweight.
